Clamps x between lo and hi (inclusive).

Returns x squared.

string

String utilities for Vyr

fn repeat(s, n)
Repeats string s n times.
fn pad_left(s, width, fill)
Pads s on the left with fill to reach width.
fn pad_right(s, width, fill)
Pads s on the right with fill to reach width.
fn is_empty(s)
Returns true if s is the empty string.
fn words(s)
Splits s by spaces into a list of words.
fn chars(s)
Returns a list of individual characters in s.
fn capitalize(s)
Capitalizes the first letter of s, lowercases the rest.
fn lines(s)
Splits s by newlines into a list of lines.
fn unwords(ws)
Joins a list of words with spaces.
fn unlines(ls)
Joins a list of lines with newlines.
fn title_case(s)
Capitalizes the first letter of each word.
fn is_upper_char(ch)
Returns true if ch is an uppercase letter.
fn is_lower_char(ch)
Returns true if ch is a lowercase letter.
fn snake_case(s)
Converts a string to snake_case (splits on uppercase and spaces).
fn kebab_case(s)
Converts a string to kebab-case (splits on uppercase and spaces).
fn strip_prefix(s, prefix)
Removes prefix from the start of s if present.
fn strip_suffix(s, suffix)
Removes suffix from the end of s if present.
fn truncate(s, max_len, ellipsis)
Truncates s to max_len characters, appending ellipsis if truncated.
fn count_occurrences(s, sub)
Counts non-overlapping occurrences of sub in s.
fn is_digit(ch)
Returns true if ch is a digit character (0-9).
fn is_alpha(ch)
Returns true if ch is an alphabetic character (a-z, A-Z).

collections

Collection utilities for Vyr

fn any(xs, pred)
Returns true if any element in xs satisfies pred.
fn all(xs, pred)
Returns true if all elements in xs satisfy pred.
fn none(xs, pred)
Returns true if no elements in xs satisfy pred.
fn count(xs, pred)
Counts how many elements in xs satisfy pred.
fn find(xs, pred)
Returns the first element in xs that satisfies pred.
fn first(xs)
Returns the first element of xs.
fn last(xs)
Returns the last element of xs.
fn take(xs, n)
Returns the first n elements of xs.
fn drop(xs, n)
Returns xs with the first n elements removed.
fn flatten(xs)
Flattens a list of lists into a single list.
fn flat_map(xs, f)
Maps f over xs, then flattens the result.
fn zip(a, b)
Pairs elements from a and b into [a_i, b_i] tuples.
fn enumerate(xs)
Pairs each element with its index as [i, x_i].
fn chunk(xs, size)
Splits xs into chunks of the given size.
fn max_of(xs)
Returns the maximum element in xs.
fn min_of(xs)
Returns the minimum element in xs.
fn unique(xs)
Returns xs with duplicate elements removed.
fn group_by(xs, f)
Groups elements by key function f into a hashmap of lists.
fn merge_sorted(a, b, f)
Merge sort helper: merges two sorted lists using key function f.
fn sort_by(xs, f)
Sorts xs by the value returned by key function f (merge sort).
fn partition(xs, pred)
Splits xs into [matches, non_matches] based on pred.
fn scan(xs, init, f)
Like reduce but returns all intermediate accumulator values.
fn window(xs, size)
Returns sliding windows of the given size over xs.
fn frequencies(xs)
Counts occurrences of each element, returning a hashmap.
fn index_of(xs, val)
Returns the index of the first occurrence of val in xs, or -1.
fn zip_with(a, b, f)
Zips a and b together using function f(a_i, b_i).
fn interleave(a, b)
Interleaves elements from a and b alternately.

result

Result type utilities for Vyr

fn map_ok(result, f)
Maps f over the Ok value, leaving Err unchanged.
fn map_err(result, f)
Maps f over the Err value, leaving Ok unchanged.
fn and_then(result, f)
Chains a function that returns a Result on the Ok value.
fn or_else(result, f)
Calls f with the result if it is Err, otherwise returns Ok.
fn flatten_result(result)
Flattens a nested Result (Ok(Ok(x)) becomes Ok(x)).
fn collect_results(xs)
Collects a list of Results into a Result of a list.
Returns Err on the first error found.
fn tap_ok(result, f)
Runs side-effect f on the Ok value, returns original result.
fn tap_err(result, f)
Runs side-effect f on the Err value, returns original result.
fn result_to_string(result)
Converts a Result to a human-readable string.

Function composition utilities for Vyr

fn pipe(fns)
Composes a list of functions left-to-right.
fn identity(x)
Returns its argument unchanged.
fn constant(x)
Returns a function that always returns x.
fn flip(f)
Returns a function with its two arguments swapped.
fn partial(f, x)
Partially applies x as the first argument to f.
fn memoize(f)
Returns a cached version of f (single-argument functions).
